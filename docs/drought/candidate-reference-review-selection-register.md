## Confirmation required before use

For each provisional candidate, local reviewers must confirm:

1. whether the geographic group and agricultural setting are correctly
   described;
2. whether August is agriculturally meaningful for the intended comparison;
3. whether the candidate should be retained, replaced, or supplemented;
4. available contextual evidence (crop stage, onset/cessation, irrigation,
   water access, pests, hail, or other events).

The selected 16 cases should then receive the evidence packet specified in the
[candidate reference review proposal](candidate-reference-review-proposal.md).
