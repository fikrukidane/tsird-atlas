## Major Features

### Phase 3 — Search, Navigation, and Measurement

**Bilingual Woreda/Tabia Gazetteer Search**
- Compact search box (280 px) in top-left toolbar, inline with all map controls
- Searches PostGIS tables `tigray_woredas_ws` and `tigray_tabias_ws`
- Bilingual results: English name + Tigrinya name (`woreda_tig` / `tabia_tig`)
- Keyboard navigation (↑ ↓ arrows, Enter, Escape)

**Zoom to Feature**
- Woreda search zooms to bbox with comfortable padding `[40, 40, 40, 40]`
- Tabia search zooms with larger padding `[80, 80, 80, 80]` and `maxZoom: 12` to preserve context and label visibility

**Orange Highlight Overlay**
- Selected feature is highlighted with a semi-transparent orange fill and 3 px stroke
- Highlight clears when a new search result is selected, when input is cleared, or on Escape
- Implemented as a plain OpenLayers vector layer (`HighlightOverlay` global)

**Navigator Map**
- Overview map positioned top-right (not obscuring scale bar or search bar)

**Full Zoom + Measurement Tools**
- Full-extent zoom button resets view to Tigray + Horn of Africa
- Distance and area measurement tools with clear button
- All controls rendered as a single horizontal toolbar row (no stacking)

**FastAPI Gazetteer Service**
- `GET /map/api/gazetteer?q=<query>` searches both Woredas and Tabias
- Returns `name_en`, `name_ti`, `type`, `bbox` (EPSG:4326)
- Full-text ILIKE search on both English and Tigrinya fields
- CORS-enabled; routed through edge nginx

### Cartographic Styling

**Tigray Woredas — Zone-based Categorical Fills**
- 7 zone classes (Central, Eastern, Mekelle, North Western, South Eastern, Southern, Western)
- Distinct muted fill colors per zone (soft blue / mint / peach / lavender / tan / rose / olive)
- OPACITY 65, WIDTH 1.5 outline, bilingual labels (NotoSansEthiopic + Arial)
- No legend displayed (cleared via `legend_mode: none`)

**Tigray Tabias — Boundary-only**
- No fill; thin 0.5 px gray outline defines internal boundaries
- No legend displayed

**Ethiopia Regions — Per-region Categorical Fills**
- 11 regions each with a distinct muted fill color
- WIDTH 2 outlines; region name labels at 1:200k–1:12M scale
- Cartographic hierarchy clearly visible: Country > Region > Woreda > Tabia

**Ethiopia Country — Bold Outline**
- WIDTH 3, near-black outline, no fill — visually dominant boundary marker

**Bilingual Label Font Stack**
- Tigrinya labels: `noto-ethiopic` (NotoSansEthiopic-Regular.ttf)
- English labels: `arial` (arial.ttf)
- Two separate LABEL blocks per CLASS with vertical offset (−7/+7 px)

**Eritrea Labels**
- Zobas (admin1): labels visible at 1:50k–1:3M
- Districts (admin2): labels visible at 1:20k–1:800k
- Light muted fills added (40–45% opacity)

**Ethiopia Roads (All types)**
- CLASS expressions corrected to match actual RDLNTYPETX values:
  `"Primary and secondary roads"` and `"Connector"` (+ fallback)

## Infrastructure

- **Docker stack**: 6 containers (`tsird-postgis`, `tsird-mapserver`, `tsird-web`, `tsird-api`, `tsird-edge`, `tsird-etl`)
- **Edge nginx**: routes `/map/api/` → tsird-api:8000, `/map/ogc` → tsird-mapserver, `/map/` → tsird-web:8080
- **Host nginx**: routes `https://lab.tigrayinsights.net/map/` → `http://127.0.0.1:18080` (Docker edge)
- **MapServer 8.6**: serving 20+ vector and raster layers
- **PostGIS 16**: backing gazetteer search and bilingual admin layers
