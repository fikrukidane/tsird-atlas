6. TROUBLESHOOTING
═════════════════════════════════════════════════════════════════════

If layers still don't display after deployment:

Q: "Layers render but GetFeatureInfo returns no features"
A: Mapfile was deployed but MapServer wasn't restarted. 
   Run: docker compose restart tsird-mapserver

Q: "QGIS shows 'ServiceException' errors"
A: QGIS may be caching capabilities. Clear cache:
   Settings → Options → Cache → Clear All Caches
   Then re-add WMS connection

Q: "Some layers render but others are still blank"
A: Only ethiopia_woredas was changed. Other UTM layers should already
   have PROJECTION blocks. Check for missing PROJECTION declarations
   in mapfile for other blank layers.

Q: "Production still shows old layer list in QGIS"  
A: GetCapabilities is cached by QGIS for 24 hours. Either:
   - Wait 24 hours, or
   - Delete WMS connection in QGIS and re-add it

7. TECHNICAL REFERENCE
═════════════════════════════════════════════════════════════════════

PROJECTION Block Explanation:
  LAYER
    NAME "ethiopia_woredas"
    PROJECTION "init=epsg:20137"  ← Tells MapServer: layer data is in
  END                               EPSG:20137 (UTM-like meters, NOT
                                    degrees). Automatically reproject to
                                    map CRS (EPSG:4326)

Without PROJECTION block:
  MapServer assumes data is in map CRS (EPSG:4326/degrees)
  → Tries to render 161k-1.6M UTM meter values as 161k-1.6M degrees
  → Coordinates are way outside map bounds
  → Result: blank/empty image

Coordinate Systems:
  EPSG:4326      = WGS 84 Geographic (degrees: -180...180, -90...90)
  EPSG:20137     = Ethiopian Grid (meters: ~160k-1.6M x, ~375k-1.6M y)
  EPSG:3857      = Web Mercator (meters for web maps)
